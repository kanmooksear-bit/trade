# AutoTrader — บอทเทรดอัตโนมัติที่ปรับกลยุทธ์ตามสภาวะตลาด และเรียนรู้จากไม้ที่ขาดทุน

บอทนี้ทำ 4 อย่างทุกวัน:

1. **อ่านสภาวะตลาด** ของแต่ละเหรียญ/หุ้น: ขาขึ้น, ขาลง, ไซด์เวย์, บีบตัว (รอเบรก), ผันผวนสูง
2. **เลือกกลยุทธ์อัตโนมัติ** ให้เหมาะกับสภาวะนั้น (ตามเทรนด์ / สวนกลับค่าเฉลี่ย / เบรกเอาท์ / โมเมนตัม)
   แล้วเรียนรู้ว่ากลยุทธ์ไหนทำกำไรได้จริงในสภาวะไหน
3. **เทรดทุกวัน** — ถ้าวันไหนไม่มีสัญญาณดีพอ จะเปิด "ไม้บังคับ" ขนาดเล็ก (ความเสี่ยงราว 0.3 เท่าของไม้ปกติ) และถือไม่เกิน 2 วัน
4. **ทบทวนทุกไม้ที่ขาดทุน** ว่าเสียเพราะอะไร แล้วปรับพารามิเตอร์ของตัวเอง — และ **ย้อนการปรับกลับเอง** ถ้าปรับแล้วผลแย่ลง

> ⚠️ **คำเตือน:** ไม่มีระบบเทรดไหนการันตีกำไร ผล backtest ในเอกสารนี้มาจาก **ข้อมูลจำลอง** ใช้แค่พิสูจน์ว่ากลไกทำงาน
> ไม่ได้บอกว่าจะได้กำไรในตลาดจริง ให้รัน paper trading (ไม่ใช้เงินจริง) อย่างน้อยหลายสัปดาห์ แล้วเริ่มเงินจริงด้วยจำนวนที่เสียได้

## เริ่มใช้งาน

```bash
pip install -r requirements.txt          # หรือ pip install -e ".[crypto,stocks,ai,dev]"

# 1) ทดสอบระบบด้วยข้อมูลจำลอง (ไม่ต้องต่อเน็ต)
python -m autotrader backtest --days 1500

# 2) เปรียบเทียบ: ปิดการเรียนรู้ / ปิดกฎเทรดทุกวัน
python -m autotrader backtest --days 1500 --no-learning
python -m autotrader backtest --days 1500 --no-daily

# 3) backtest ด้วยข้อมูลจริง (ต้องต่อเน็ต)
cp config.example.yaml config.yaml
python -m autotrader -c config.yaml backtest --days 1000 --source ccxt

# 4) Paper trading: รันวันละครั้ง (บันทึกทุกอย่างใน data/autotrader.db)
python -m autotrader -c config.yaml run
python -m autotrader -c config.yaml report      # ผลงาน + เหตุผลที่ขาดทุน + การปรับล่าสุด
python -m autotrader -c config.yaml params      # พารามิเตอร์ปัจจุบันที่บอทปรับเอง
```

### ให้รันเองทุกวัน

แบบ daemon (รันค้างไว้: รอบหลักวันละครั้ง + เช็คสต็อปทุกชั่วโมง):

```bash
python -m autotrader -c config.yaml daemon
```

หรือใช้ cron (เวลา UTC; 00:05 UTC = 07:05 เวลาไทย):

```cron
5 0 * * *  cd /path/to/trade && python -m autotrader -c config.yaml run   >> data/bot.log 2>&1
0 * * * *  cd /path/to/trade && python -m autotrader -c config.yaml check >> data/bot.log 2>&1
```

รันซ้ำในวันเดียวกันได้อย่างปลอดภัย — บอทจำว่าแท่งไหนประมวลผลไปแล้ว

### แจ้งเตือนทาง Telegram

ตั้ง `TELEGRAM_BOT_TOKEN` และ `TELEGRAM_CHAT_ID` ใน environment แล้วบอทจะส่งสรุปรายวัน, ไม้ที่เปิด/ปิด และผลการทบทวนไม้ขาดทุนให้

## การทำงานในแต่ละวัน

```
ข้อมูลแท่งรายวันที่ปิดแล้ว
   │
   ▼
ตรวจสภาวะตลาด (ADX, Efficiency Ratio, ความชัน EMA, เปอร์เซ็นไทล์ความผันผวน, ความกว้าง Bollinger)
   │   ต้องเห็นสภาวะใหม่ติดกัน N แท่งก่อนเปลี่ยน (กันสลับไปมา) ยกเว้น "ผันผวนสูง" เปลี่ยนทันที
   ▼
จัดการไม้ที่ถืออยู่: สต็อป / เป้ากำไร / เลื่อนบังทุน / trailing stop / หมดเวลา / สภาวะเปลี่ยน / สัญญาณกลับทิศ
   │
   ▼
เรียนรู้จากไม้ที่ปิด ──► ไม้ขาดทุน → วิเคราะห์สาเหตุ → เก็บหลักฐาน → ปรับพารามิเตอร์ → ทดลอง → เก็บไว้หรือย้อนกลับ
   │
   ▼
ให้คะแนนทุกคู่ (เหรียญ × กลยุทธ์) = ความแรงสัญญาณ × น้ำหนักของกลยุทธ์ในสภาวะนั้น (เรียนรู้จากผลจริง)
   │
   ▼
เปิดไม้ที่ดีที่สุด (ภายใต้กฎความเสี่ยง) ──► ถ้าไม่มีเลย: เปิดไม้บังคับขนาดเล็ก (กฎเทรดทุกวัน)
```

### กลยุทธ์ที่เลือกใช้ได้

| กลยุทธ์ | ถนัดในสภาวะ | เข้าเมื่อ |
|---|---|---|
| `trend` ตามเทรนด์ | ขาขึ้น / ขาลง | EMA เร็ว/ช้าเรียงตัว + ADX แรงพอ |
| `mean_reversion` สวนกลับ | ไซด์เวย์ | ราคาหลุด Bollinger + RSI สุดโต่ง |
| `breakout` เบรกเอาท์ | บีบตัว | ปิดเหนือ/ใต้กรอบ N แท่ง + volume ยืนยัน |
| `momentum` โมเมนตัม | ผันผวนสูง | เคลื่อนที่แรงหลาย ATR และยังไม่ overbought/oversold สุดๆ |

ตารางนี้เป็นแค่ "ค่าเริ่มต้น" — บอทจะเพิ่ม/ลดน้ำหนักเองจากผลจริงของแต่ละคู่ (สภาวะ, กลยุทธ์)
และถ้าคู่ไหนแพ้ติดกัน 3 ครั้ง จะพักคู่นั้น 10 วัน

### บอททบทวนไม้ขาดทุนอย่างไร

ทุกไม้ที่ขาดทุนจะถูกวิเคราะห์จากข้อมูลตอนเข้าและตอนออก ตัวอย่างสาเหตุที่ตรวจได้:

| รหัส | ความหมาย | สิ่งที่บอทปรับ |
|---|---|---|
| `REGIME_SHIFT` | สภาวะตลาดเปลี่ยนระหว่างถือ | ให้ออกเมื่อสภาวะเปลี่ยน / ตรวจจับการเปลี่ยนเร็วขึ้น |
| `VOLATILITY_SHOCK` | ความผันผวนพุ่งกะทันหัน | จับสภาวะผันผวนสูงเร็วขึ้น + ลดขนาดไม้ช่วงผันผวน |
| `COUNTER_TREND` | เทรดสวนเทรนด์ใหญ่ (EMA200) | เปิดตัวกรองเทรนด์ใหญ่ |
| `CHASED_ENTRY` | ไล่ราคา เข้าไกลจากค่าเฉลี่ย | ลดระยะที่ยอมไล่ |
| `WEAK_SIGNAL` | สัญญาณอ่อน | เพิ่มเกณฑ์ความแรงขั้นต่ำ |
| `FALSE_BREAKOUT` | เบรกหลอก | ต้องการการยืนยันมากขึ้น |
| `GAVE_BACK_PROFIT` | เคยกำไรแล้วปล่อยกลับมาขาดทุน | เลื่อนบังทุน/trailing เร็วขึ้น |
| `STOP_TOO_TIGHT` | (ตรวจย้อนหลัง 5 แท่ง) โดนสต็อปแล้วราคากลับไปทางที่คาด | ขยายระยะสต็อป |
| `COSTS` / `STALLED` / `GAP_THROUGH_STOP` | ค่าธรรมเนียมกินกำไร / ถือนานไม่ไปไหน / ราคากระโดดข้ามสต็อป | เป้าไกลขึ้น / ถือสั้นลง / ลดขนาดไม้ |
| `NORMAL_VARIANCE` | สัญญาณถูกต้อง แค่แพ้ตามสถิติ | **ไม่ปรับอะไร** |

กลไกกัน "ปรับมั่ว" (overfitting):

- **ต้องมีหลักฐานซ้ำ** — สาเหตุเดียวกันต้องเกิดกับกลยุทธ์เดียวกัน 2 ครั้ง (ตั้งได้) ถึงจะปรับ
- **ต้องมีสถิติรองรับ** — เช่นจะเปิดตัวกรองเทรนด์ใหญ่ก็ต่อเมื่อไม้สวนเทรนด์ในอดีต *แย่กว่าจริง* เทียบกับไม้อื่น
- **มีกรอบ** — ทุกพารามิเตอร์มีค่าต่ำสุด/สูงสุด และขยับทีละ step
- **ทดลองแล้วตัดสิน** — การปรับทุกครั้งถูก "ทดลองงาน" 6 ไม้ ถ้าค่าเฉลี่ย R แย่กว่าก่อนปรับ จะย้อนกลับอัตโนมัติ
- ไม้บังคับรายวันจะไม่ถูกใช้ปรับกฎการเข้าของกลยุทธ์ (เพราะไม่ได้เข้าตามสัญญาณจริง)

ตัวอย่างรูปแบบข้อความทบทวน (ดูของจริงได้ด้วยคำสั่ง `report`):

```
ไม้ #812 SOL/USDT breakout Long ขาดทุน -48.10 (-1.00R) ออกด้วย stop หลังถือ 2 แท่ง
  1. เบรกหลอก: โดนสต็อปภายใน 2 แท่งหลังเบรก — ต้องการการยืนยันมากขึ้น (ระยะเบรก + volume)
  • ปรับ breakout.confirm_atr: 0.0 → 0.1 (FALSE_BREAKOUT)
  • ปรับ breakout.volume_mult: 1.2 → 1.3 (FALSE_BREAKOUT)
```

### ให้ AI (Claude) ช่วยวิเคราะห์ (ไม่บังคับ)

ตั้ง `llm_review.enabled: true` และ `ANTHROPIC_API_KEY` แล้วทุกไม้ที่ขาดทุนจะได้บทวิเคราะห์ภาษาไทยเพิ่ม
ถ้าเปิด `apply_suggestions: true` AI จะเสนอปรับพารามิเตอร์ได้ แต่ยังถูกจำกัดให้อยู่ในกรอบ และขยับได้ไม่เกิน 2 step ต่อครั้ง
(ระบบวิเคราะห์แบบกฎทำงานเสมอ AI เป็นแค่ส่วนเสริม)

## การคุมความเสี่ยง (สำคัญกว่ากฎเทรดทุกวัน)

- เสียได้สูงสุด ~1% ของทุนต่อไม้, ไม้เดียวไม่เกิน 30% ของทุน, exposure รวมไม่เกิน 100%
- ช่วงผันผวนสูง ลดขนาดไม้ลงครึ่งหนึ่ง (บอทปรับตัวเลขนี้เองได้)
- แพ้ติดกัน 3 ไม้ → ลดขนาดความเสี่ยงลงครึ่ง (ต่ำสุด 0.25 เท่า) แล้วค่อยเพิ่มคืนเมื่อชนะ
- ขาดทุนเกิน 3% ในวันเดียว → หยุดเปิดไม้ใหม่วันนั้น
- ทุนลดจากจุดสูงสุด 25% → **หยุดทั้งระบบ** จนกว่าจะสั่ง `python -m autotrader reset-halt`

ถ้ากฎความเสี่ยงไม่อนุญาต วันนั้นบอทจะไม่เปิดไม้ และบอกเหตุผลใน log/Telegram

## ผล backtest บนข้อมูลจำลอง (ตัวอย่าง)

5 เหรียญจำลอง ~1,550 วัน ทุนเริ่มต้น 10,000 (ค่าธรรมเนียม 0.1% + slippage 0.05%):

| แบบ | ผลตอบแทน | Max DD | Sharpe | วันที่มีไม้ใหม่ |
|---|---|---|---|---|
| ครบทุกระบบ (เรียนรู้ + เทรดทุกวัน) | +12.1% | 4.6% | 0.88 | 99% |
| ปิดการเรียนรู้ (`--no-learning`) | +9.0% | 6.1% | 0.53 | 98% |
| ปิดกฎเทรดทุกวัน (`--no-daily`) | +32.2% | 3.2% | 1.86 | 12% |

สิ่งที่ตัวเลขนี้บอก (บนข้อมูลจำลอง):
- **การเรียนรู้จากไม้ที่แพ้ช่วยจริง** — ผลตอบแทนดีขึ้น drawdown ต่ำลง
- **กฎ "ต้องเทรดทุกวัน" มีต้นทุน** — ไม้บังคับรวมกันขาดทุน (ค่าธรรมเนียม + เข้าโดยไม่มี edge) บอทจะลดขนาดไม้บังคับลงเองเมื่อแพ้
  ถ้าต้องการผลตอบแทนต่อความเสี่ยงที่ดีที่สุด ให้พิจารณาตั้ง `trade_every_day: false`

## ข้อจำกัดที่ควรรู้

- ตัดสินใจจาก **แท่งรายวัน** สต็อปในโหมด live ถูกเช็คด้วยราคาล่าสุดทุก `stop_check_minutes` (ไม่ได้วาง stop order ไว้ที่ exchange)
  ถ้าบอทดับ สต็อปจะไม่ทำงานจนกว่าจะรันใหม่
- โหมด live รองรับ spot ผ่าน ccxt (เริ่มด้วย `sandbox: true` เสมอ) ยังไม่ได้ทดสอบกับบัญชีจริง
- ถือได้ 1 สถานะต่อ 1 symbol — ยิ่งมีหลาย symbol ยิ่งเทรดได้ทุกวันง่ายขึ้น
- ใน spot ที่ห้าม short ช่วงตลาดลงทุกตัว บอทอาจไม่มีไม้ให้เปิด (จะแจ้งเหตุผล)
