# AutoTrader — บอทเทรดอัตโนมัติที่ปรับกลยุทธ์ตามสภาวะตลาด และเรียนรู้จากไม้ที่ขาดทุน

รองรับ **XAUUSD (ทองคำ) ผ่าน MetaTrader 5 / HFM** โดยตรง และยังใช้กับคริปโต (ccxt) / หุ้น (yfinance) ได้

ทุกแท่งราคาที่ปิด (เช่น ทุก 1 ชั่วโมง) บอทจะ:

1. **อ่านสภาวะตลาด**: ขาขึ้น, ขาลง, ไซด์เวย์, บีบตัว (รอเบรก), ผันผวนสูง
2. **เลือกกลยุทธ์อัตโนมัติ** ให้เหมาะกับสภาวะนั้น (ตามเทรนด์ / สวนกลับค่าเฉลี่ย / เบรกเอาท์ / โมเมนตัม)
   แล้วเรียนรู้ว่ากลยุทธ์ไหนได้ผลจริงในสภาวะไหน
3. **เทรดทุกวัน** — ถ้าถึงเวลาที่กำหนดแล้ววันนั้นยังไม่มีสัญญาณดีพอ จะเปิด "ไม้บังคับ" ขนาดเล็ก (เสี่ยงไม่เกินไม้ปกติ) ถือไม่นาน
4. **ทบทวนทุกไม้ที่ขาดทุน** ว่าเสียเพราะอะไร → ถ้าสาเหตุเดิมเกิดซ้ำ จะ **ทดสอบวิธีแก้กับข้อมูลย้อนหลังก่อน**
   และปรับเฉพาะเมื่อพิสูจน์ได้ว่าดีกว่า → หลังปรับยังติดตามผลจริงต่อ ถ้าแย่ลงจะ **ย้อนกลับเอง**

> ⚠️ **คำเตือน:** ไม่มีระบบเทรดไหนการันตีกำไร ทองคำใช้ leverage สูง เสียเงินได้เร็ว
> ให้ backtest กับข้อมูลจริงของโบรก → paper trading หลายสัปดาห์ → ค่อยเริ่มเงินจริงด้วยจำนวนที่เสียได้

## XAUUSD กับ HFM (MetaTrader 5)

### สิ่งที่บอทจัดการให้

- ราคา **ทศนิยม 2 ตำแหน่ง** (SL/TP ถูกปัดเป็น 0.01 ตามที่ MT5 ต้องการ)
- ขนาดไม้เป็น **lot** (1 lot = 100 ออนซ์, ขั้นต่ำ 0.01, ทีละ 0.01) — อ่านค่าจริงจากโบรกผ่าน MT5
- **SL/TP วางไว้บนเซิร์ฟเวอร์ของ HFM** พร้อมคำสั่งเปิด → ถึงคอมดับ/บอทหยุด สต็อปก็ยังทำงาน
- trailing stop / เลื่อนบังทุน ส่งคำสั่งแก้ SL ไปที่เซิร์ฟเวอร์ทุกแท่ง
- ไม้ที่ถูกปิดด้วย SL/TP บนเซิร์ฟเวอร์ บอทจะดึงประวัติจาก MT5 มาบันทึก (ราคาจริง, ค่าคอม, swap) แล้วนำไปทบทวน
- เปิด **Sell ได้** (CFD), คิด **spread + ค่าคอมต่อ lot** ใน backtest / paper
- คำสั่งของบอทมี magic number ของตัวเอง ไม่ยุ่งกับไม้ที่คุณเทรดเอง

### ติดตั้ง (บน Windows — แพ็กเกจ MetaTrader5 ของ Python ใช้ได้เฉพาะ Windows)

1. ติดตั้งโปรแกรม MT5 ของ HFM แล้วล็อกอินบัญชี (แนะนำบัญชี Demo ก่อน)
2. ใน MT5 กดปุ่ม **Algo Trading** ให้เป็นสีเขียว และเพิ่ม `XAUUSD` ใน Market Watch (เช็คชื่อให้ตรง บางบัญชีมีตัวต่อท้าย)
3. ติดตั้ง Python 3.10+ แล้ว:

```bat
pip install -r requirements.txt
pip install MetaTrader5
copy config.xauusd.example.yaml config.yaml
```

4. (ถ้าไม่อยากให้บอทใช้บัญชีที่ล็อกอินค้างไว้) ตั้งค่า login ผ่าน environment variable — **อย่าใส่รหัสผ่านในไฟล์**:

```bat
set MT5_LOGIN=12345678
set MT5_PASSWORD=รหัสผ่าน
set MT5_SERVER=ชื่อเซิร์ฟเวอร์ตามหน้าล็อกอิน MT5
```

### ขั้นตอนใช้งาน

```bat
:: 1) ทุนพอกับ lot ขั้นต่ำไหม (สำคัญมากสำหรับทอง)
python -m autotrader -c config.yaml sizing

:: 2) backtest ด้วยข้อมูลจริงจาก MT5 ของคุณ (เช่น 1 ปีย้อนหลัง)
python -m autotrader -c config.yaml backtest --days 365
python -m autotrader -c config.yaml backtest --days 365 --no-learning   (เทียบ)
python -m autotrader -c config.yaml backtest --days 365 --no-daily      (เทียบ)

:: 3) paper trading ด้วยราคาจริง (broker.type: paper) — ปล่อยรันไว้
python -m autotrader -c config.yaml daemon

:: 4) ดูผล / เหตุผลที่ขาดทุน / การปรับ
python -m autotrader -c config.yaml report
python -m autotrader -c config.yaml params

:: 5) เงินจริง: แก้ config เป็น  mode: live  และ  broker.type: mt5  แล้วรัน daemon
```

ถ้ารัน Python บนเครื่องที่ไม่มี MT5: export ประวัติราคาจาก MT5 (View → Symbols → Bars → เลือก XAUUSD, H1 → Export)
แล้วตั้ง `data.source: csv` ชี้ไปที่ไฟล์นั้น เพื่อ backtest ได้

`daemon` จะตรวจทุก 30 วินาทีว่าแท่ง H1 ปิดหรือยัง → ปิดแล้วรันรอบทันที, ระหว่างนั้นตรวจทุก 15 นาทีว่าไม้ไหนโดน SL/TP ไปแล้ว
เวลาใน log เป็นเวลาเซิร์ฟเวอร์ของ HFM (ตรงกับที่เห็นใน MT5)

### เรื่องทุนกับ lot ขั้นต่ำ (อ่านก่อนใช้เงินจริง)

0.01 lot ทอง = 1 ออนซ์ ราคาขยับ 1 ดอลลาร์ = กำไร/ขาดทุน 1 ดอลลาร์ ถ้าสต็อปห่าง 15 ดอลลาร์ ไม้เล็กสุดก็เสี่ยง 15 ดอลลาร์แล้ว

- บอทเสี่ยง 1% ต่อไม้ ถ้า 1% ต่ำกว่า 0.01 lot จะยอมใช้ 0.01 lot ได้ **ถ้าเสี่ยงไม่เกิน 2%** (`max_min_lot_risk`) ไม่งั้นข้ามไม้นั้นและบอกว่าต้องมีทุนเท่าไร
- ไม้บังคับรายวันจะ **ไม่เสี่ยงเกินไม้ปกติ (1%)** — ถ้าทุนน้อย วันนั้นอาจไม่มีไม้บังคับ
- ยิ่ง timeframe ใหญ่ สต็อปยิ่งกว้าง (D1 ต้องใช้ทุนมากกว่า H1 หลายเท่า) — คำสั่ง `sizing` จะคำนวณจากราคาจริงให้
- ทุนน้อยแล้วใช้ 0.01 lot ที่เสี่ยง 2% ต่อไม้ → แพ้ติดกันไม่กี่ไม้ก็ถึง kill switch (DD 20%)

## การทำงานในแต่ละรอบ (ทุกแท่งที่ปิด)

```
แท่งราคาที่ปิดแล้ว
   │
   ▼
ตรวจสภาวะตลาด (ADX, Efficiency Ratio, ความชัน EMA, เปอร์เซ็นไทล์ความผันผวน, ความกว้าง Bollinger)
   │   ต้องเห็นสภาวะใหม่ติดกัน N แท่งก่อนเปลี่ยน (กันสลับไปมา) ยกเว้น "ผันผวนสูง" เปลี่ยนทันที
   ▼
จัดการไม้ที่ถืออยู่: SL / TP / เลื่อนบังทุน / trailing / หมดเวลา / สภาวะเปลี่ยน / สัญญาณกลับทิศ
   │
   ▼
เรียนรู้จากไม้ที่ปิด ──► ขาดทุน → วิเคราะห์สาเหตุ → เกิดซ้ำ → ทดสอบย้อนหลัง → ผ่านจึงปรับ → ติดตามผล → เก็บไว้/ย้อนกลับ
   │
   ▼
ให้คะแนน (symbol × กลยุทธ์) = ความแรงสัญญาณ × น้ำหนักกลยุทธ์ในสภาวะนั้น (เรียนรู้จากผลจริง)
   │
   ▼
เปิดไม้ที่ดีที่สุดภายใต้กฎความเสี่ยง ──► ถึงเวลาแล้ววันนี้ยังไม่มีไม้: เปิดไม้บังคับขนาดเล็ก
```

### กลยุทธ์

| กลยุทธ์ | ถนัดในสภาวะ | เข้าเมื่อ |
|---|---|---|
| `trend` ตามเทรนด์ | ขาขึ้น / ขาลง | EMA เร็ว/ช้าเรียงตัว + ADX แรงพอ |
| `mean_reversion` สวนกลับ | ไซด์เวย์ | ราคาหลุด Bollinger + RSI สุดโต่ง |
| `breakout` เบรกเอาท์ | บีบตัว | ปิดเหนือ/ใต้กรอบ N แท่ง + volume ยืนยัน |
| `momentum` โมเมนตัม | ผันผวนสูง | เคลื่อนที่แรงหลาย ATR และยังไม่ overbought/oversold สุดๆ |

ตารางนี้เป็นค่าเริ่มต้น — บอทเพิ่ม/ลดน้ำหนักเองจากผลจริงของแต่ละคู่ (สภาวะ, กลยุทธ์) และพักคู่ที่แพ้ติดกัน 3 ครั้ง

### บอททบทวนไม้ขาดทุนอย่างไร

| รหัส | ความหมาย | สิ่งที่บอทเสนอปรับ (ต้องผ่านการทดสอบย้อนหลังก่อน) |
|---|---|---|
| `REGIME_SHIFT` | สภาวะตลาดเปลี่ยนระหว่างถือ | ให้กลยุทธ์นั้นออกทันทีเมื่อสภาวะเปลี่ยน |
| `COUNTER_TREND` | เทรดสวนเทรนด์ใหญ่ (EMA200) | เปิดตัวกรองเทรนด์ใหญ่ |
| `CHASED_ENTRY` | ไล่ราคา เข้าไกลจากค่าเฉลี่ย | ลดระยะที่ยอมไล่ |
| `WEAK_SIGNAL` | สัญญาณอ่อน | เพิ่มเกณฑ์ความแรงขั้นต่ำ |
| `FALSE_BREAKOUT` | เบรกหลอก | ต้องการการยืนยันมากขึ้น |
| `GAVE_BACK_PROFIT` | เคยกำไรแล้วปล่อยกลับมาขาดทุน | เลื่อนบังทุน/trailing เร็วขึ้น |
| `STOP_TOO_TIGHT` | (ตรวจย้อนหลังหลังปิดไม้) โดนสต็อปแล้วราคากลับไปทางที่คาด | ขยายระยะสต็อป |
| `COSTS` / `STALLED` | spread/ค่าคอมกินกำไร / ถือนานไม่ไปไหน | เป้าไกลขึ้น / ถือสั้นลง |
| `VOLATILITY_SHOCK` / `GAP_THROUGH_STOP` | ความผันผวนพุ่ง / ราคากระโดดข้ามสต็อป | **อธิบายอย่างเดียว ไม่ปรับ** (เหตุจากตลาด) |
| `NORMAL_VARIANCE` | สัญญาณถูกต้อง แค่แพ้ตามสถิติ | **ไม่ปรับอะไร** |

### กลไกกัน "ปรับมั่ว" (overfitting)

1. **ต้องเกิดซ้ำ** — สาเหตุเดียวกันกับกลยุทธ์เดียวกัน 2 ครั้ง ถึงจะพิจารณา
2. **ต้องมีสถิติรองรับ** — เช่น ไม้สวนเทรนด์ในอดีตต้อง *แย่กว่าจริง* ถึงจะเปิดตัวกรอง
3. **ทดสอบย้อนหลังก่อนปรับ (what-if)** — เล่นกลยุทธ์นั้นซ้ำกับ 1,000 แท่งล่าสุด ทั้งค่าเดิมและค่าใหม่ (ใช้โค้ดสัญญาณ/จุดออก/ต้นทุนเดียวกับของจริง)
   จะปรับก็ต่อเมื่อ ค่าใหม่ดีขึ้นอย่างน้อย 1R **และไม่แย่ลงทั้งครึ่งแรกและครึ่งหลัง** ของช่วงทดสอบ
4. **มีกรอบ** — ทุกพารามิเตอร์มีค่าต่ำสุด/สูงสุด ขยับทีละ step
5. **ทดลองงาน** — หลังปรับ ติดตามผลจริง 10 ไม้ ถ้าเฉลี่ยแย่กว่าก่อนปรับชัดเจน (0.2R) จะย้อนกลับเอง
6. ตัวตรวจจับสภาวะตลาด (ใช้ร่วมทุกกลยุทธ์) **ไม่ถูกปรับจากไม้ที่แพ้ไม้เดียว**
7. ไม้บังคับรายวันไม่ถูกใช้ปรับกฎการเข้าของกลยุทธ์

ตัวอย่างข้อความ (ดูของจริงด้วย `report`):

```
ไม้ #212 XAUUSD breakout Long ขาดทุน -14.80 (-1.00R) ออกด้วย stop หลังถือ 2 แท่ง
  1. เบรกหลอก: โดนสต็อปภายใน 2 แท่งหลังเบรก — ต้องการการยืนยันมากขึ้น (ระยะเบรก + volume)
  • ปรับ breakout.confirm_atr: 0.0 → 0.1 (FALSE_BREAKOUT) [ทดสอบย้อนหลัง 1000 แท่ง: ค่าเดิม 31 ไม้ -2.4R → ค่าใหม่ 26 ไม้ +1.9R ...]
```

### ให้ AI (Claude) ช่วยวิเคราะห์ (ไม่บังคับ)

ตั้ง `llm_review.enabled: true` และ `ANTHROPIC_API_KEY` → ไม้ที่ขาดทุนจะมีบทวิเคราะห์ภาษาไทยเพิ่ม
ถ้าเปิด `apply_suggestions: true` ข้อเสนอของ AI ก็ต้องผ่านกรอบ + การทดสอบย้อนหลังเหมือนกัน

## การคุมความเสี่ยง (สำคัญกว่ากฎเทรดทุกวัน)

- เสียได้ ~1% ของทุนต่อไม้ (หรือ lot ขั้นต่ำถ้าไม่เกิน 2%), ช่วงผันผวนสูงลดขนาดไม้ครึ่งหนึ่ง
- แพ้ติดกัน 3 ไม้ → ลดความเสี่ยงลงครึ่ง (ต่ำสุด 0.25 เท่า) แล้วค่อยเพิ่มคืนเมื่อชนะ
- ขาดทุนเกิน 3% ในวันเดียว → หยุดเปิดไม้ใหม่วันนั้น
- ทุนลดจากจุดสูงสุด 20% (ทอง) / 25% (ค่าเริ่มต้น) → **หยุดทั้งระบบ** จนกว่าจะสั่ง `python -m autotrader reset-halt`

## ผลการทดสอบ (อ่านอย่างระวัง)

ยังไม่ได้ทดสอบกับข้อมูล XAUUSD จริง — ให้รัน `backtest` กับข้อมูล MT5 ของคุณเอง ตัวเลขด้านล่างเป็นการทดสอบกลไก:

**1) ข้อมูลจำลอง 5 สินทรัพย์ แท่งรายวัน ~1,550 วัน** (ทุน 10,000, ค่าธรรมเนียม 0.1%)

| แบบ | ผลตอบแทน | Max DD | Sharpe |
|---|---|---|---|
| ครบทุกระบบ | +9.9% | 5.8% | 0.61 |
| ปิดการเรียนรู้ (`--no-learning`) | +9.0% | 6.1% | 0.53 |
| ปิดกฎเทรดทุกวัน (`--no-daily`) | +13.3% | 5.2% | 0.78 |

**2) ข้อมูลจริง EURUSD H1 ~10 เดือน** (คู่เงินเดียว — ข้อมูลทองจริงดึงจากเครื่องที่พัฒนาไม่ได้)

| แบบ | ผลตอบแทน | Max DD | Sharpe |
|---|---|---|---|
| ครบทุกระบบ | +7.0% | 9.1% | 0.84 |
| ปิดการเรียนรู้ | +9.4% | 6.3% | 1.10 |
| ปิดกฎเทรดทุกวัน | +9.9% | 10.0% | 1.11 |
| (เวอร์ชันแรกที่ปรับโดยไม่ทดสอบย้อนหลัง) | −6.3% | 11.6% | −0.92 |

**3) ข้อมูลจำลองแบบทอง H1 ทุน 1,000** — ทุกแบบขาดทุนจนถึง kill switch 20%: ทุนน้อยทำให้ทุกไม้ต้องใช้ 0.01 lot ที่เสี่ยง ~2%
และข้อมูลจำลองรายชั่วโมงไม่มีพฤติกรรมจริงของตลาดทอง จึงสรุปอะไรเรื่องทองไม่ได้

สิ่งที่ตัวเลขบอก:
- บนข้อมูลจริง เวอร์ชันแรกที่ปรับตัวเองจากไม้แพ้ทีละไม้ **ทำให้ผลแย่ลง** (ปรับค่ากลางของตัวจับสภาวะตลาดจนสุดขอบ)
  จึงเพิ่มการทดสอบย้อนหลังก่อนปรับ ตอนนี้การปรับตัว **ไม่ทำร้ายผลแล้ว แต่ก็ยังไม่มีหลักฐานว่าช่วยให้ดีขึ้นบนข้อมูลจริง**
  (ความต่างระดับนี้อยู่ในช่วงที่เกิดจากโชคได้ — ต้องใช้ข้อมูลมากกว่านี้)
- **กฎ "ต้องเทรดทุกวัน" มีต้นทุนทุกชุดข้อมูล** — ไม้บังคับเข้าโดยไม่มีความได้เปรียบ ถ้าเน้นผลลัพธ์ให้พิจารณา `trade_every_day: false`

## ใช้กับคริปโต / หุ้น

```bash
cp config.example.yaml config.yaml          # คริปโตผ่าน ccxt (ค่าเริ่มต้น: Binance spot, paper)
python -m autotrader -c config.yaml backtest --days 1000 --source ccxt
python -m autotrader -c config.yaml daemon
```

แจ้งเตือน Telegram: ตั้ง `TELEGRAM_BOT_TOKEN` และ `TELEGRAM_CHAT_ID` (ส่งเมื่อมีไม้เปิด/ปิด/ทบทวน และสรุปวันละครั้ง)

| `autotrader/regime.py` | ตรวจจับสภาวะตลาด |

| `autotrader/review.py` | วิเคราะห์สาเหตุไม้ขาดทุน + ตรวจย้อนหลัง |
| `autotrader/whatif.py` | ทดสอบการปรับกับข้อมูลย้อนหลังก่อนใช้จริง |
| `autotrader/adapter.py` | ปรับพารามิเตอร์ + ทดลองงาน/ย้อนกลับ |

| `autotrader/broker.py` | Paper broker, MT5 broker (HFM), ccxt broker |
| `autotrader/mt5_connector.py` | เชื่อมต่อโปรแกรม MT5 |

## ข้อจำกัดที่ควรรู้

- ส่วนเชื่อมต่อ MT5 เขียนตามเอกสารทางการของแพ็กเกจ MetaTrader5 และทดสอบกับ MT5 จำลอง **ยังไม่ได้ทดสอบกับเทอร์มินัล HFM จริง** — เริ่มที่บัญชี Demo
- ไม่ได้จำลอง swap ข้ามคืนใน backtest/paper (ในบัญชีจริงบอทบันทึก swap จาก MT5 ให้)
- ถือได้ 1 สถานะต่อ symbol — ทองตัวเดียวจึงถือทีละไม้
- ถ้าบัญชี MT5 เป็นแบบ netting (ไม่ใช่ hedging) อย่าเทรด XAUUSD ด้วยมือในบัญชีเดียวกับบอท เพราะสถานะจะรวมกัน
- ผลบนข้อมูลจำลองหรือคู่เงินอื่นไม่ได้บอกว่าจะได้กำไรกับทองจริง
